一、引言

欢迎使用 Camera Stream Monitor（以下简称"本应用"）。我们深知隐私对用户的重要性，因此制定本隐私政策，向您透明地说明我们如何处理您的个人信息。使用本应用即表示您已阅读、理解并同意本政策。

二、信息收集

2.1 我们收集的信息类型

信息类型 用途说明 是否必需
摄像头画面 用于实时视频预览、本地录制和用户主动发起的网络推流传输 是（核心功能）
麦克风音频 在视频录制或推流时同步采集音频 是（核心功能）
设备存储 将录制的视频文件保存到设备本地存储目录 是（功能需要）
网络连接状态 仅在用户配置并启动 RTMP/RTSP/SRT 推流时使用 是（功能需要）
语言偏好设置 记录用户选择的应用界面语言（中文/英文） 否（可选）

2.2 我们不收集的信息

为保障您的隐私安全，我们郑重承诺不会收集以下任何信息：

  • 姓名、手机号、邮箱地址等个人身份信息
  • GPS 定位或地理位置信息
  • 通讯录、通话记录、短信内容
  • 设备唯一标识符（IMEI/IDFA 等）
  • 任何形式的用户行为追踪数据

三、信息使用方式

  1. 摄像头与音频数据：仅用于您在本应用内主动发起的预览、录制和推流操作，不会上传至任何远程服务器
  2. 本地存储文件：录制的视频保存在您设备的本地存储中（默认路径：/Movies/VideoMonitor/），您可以随时通过应用内功能或系统文件管理器查看和删除
  3. 网络传输：仅在您手动输入推流地址并点击启动后，才通过 RTMP/RTSP/SRT 协议将音视频流传输到您指定的目标服务器地址
  4. 语言偏好：以加密形式存储在应用的本地 SharedPreferences 中，不对外共享或上传

四、信息存储与安全

  • 所有数据均存储在您的本地设备上，我们不运营任何云服务器来存储您的数据
  • 录制的视频文件完全由您控制，可随时删除
  • 卸载本应用后，所有应用数据（包括录制文件、设置项）将被自动清除
  • 本应用不包含任何用户账号系统，无需注册登录即可使用全部功能

五、第三方 SDK 说明

SDK 名称 用途 是否独立收集数据
RootEncoder
(pedroSG94)		 音视频编码与多协议推流处理 否
ExoPlayer / Media3
(Google)		 视频播放引擎，支持多种流媒体协议 否
CameraX
(Google)		 Android 官方摄像头采集框架 否

(Square)		 HTTP 网络请求库（备用） 否

以上第三方 SDK 均遵循各自的开源许可协议，不会脱离本应用独立收集或传输您的个人信息。

六、权限使用说明

权限名称 使用目的
CAMERA（摄像头） 获取摄像头画面用于实时预览、录制和推流
RECORD_AUDIO（录音） 录制视频时同步采集麦克风音频
WRITE_EXTERNAL_STORAGE
READ_EXTERNAL_STORAGE		 将录制的视频文件保存到设备外部存储，以及读取已有录制文件进行回放和管理
INTERNET（网络） 用于 RTMP/RTSP/SRT 推流传输和网络拉流播放
FOREGROUND_SERVICE
（前台服务）		 支持后台持续录制和推流，避免被系统杀掉进程
POST_NOTIFICATIONS
（通知权限）		 显示录制/推流状态的通知栏提醒

七、未成年人保护

本应用不面向 13 周岁以下儿童设计和推广。由于本应用涉及摄像头和麦克风的使用，建议未成年人在监护人指导下使用。我们不会故意收集儿童的个人信息。

八、您的权利

  • 知情权：您有权了解本应用收集了哪些信息及用途（即本政策所述内容）
  • 控制权：您可以随时拒绝授予任何权限（但可能导致部分核心功能无法使用）
  • 删除权：您可以随时在应用内删除录制的视频文件
  • 清除权：您可以通过 系统设置 → 应用管理 → Camera Stream Monitor → 清除数据 来彻底删除所有应用数据
  • 卸载权：您可以随时卸载本应用以停止使用

九、隐私政策的更新

我们可能会因法律法规变化或功能更新而修改本隐私政策。重大变更将通过应用内提示的方式通知您。建议您定期查阅本页面。
